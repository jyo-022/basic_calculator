 🧮 Basic Calculator (Python)

This is a simple command-line calculator written in Python. It allows users to perform basic arithmetic operations including addition, subtraction, multiplication, and division. The program runs in a loop until the user chooses to quit.

🚀 Features

* Addition, Subtraction, Multiplication, Division
* Division by zero handling
* Menu-driven interface
* Runs until the user quits (press `5`)

 📂 How to Run

1. Clone the repository:
    git clone https://github.com/your-username/your-repo-name.git
  

2. Navigate to the project directory:
     cd your-repo-name
 

3. Run the script:
      python basic_calculator.py

 📌 Requirements

* Python 3.x
